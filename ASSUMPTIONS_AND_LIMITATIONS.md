# ASSUMPTIONS_AND_LIMITATIONS

Educational/simulated case. No independent engineering report, structural assessment, legal opinion, tax opinion, real credit file, negotiated PPA, lender approval or independent model audit.

Public repository contains only synthetic project/offtaker/site data and public-source metadata. Raw snapshots, proprietary quotes, reviewer-sensitive notes, credentials and hidden truth are excluded.

P50/P90 is an analytical approximation, not a formal bankable yield assessment. Debt terms, credit grades, PPA clauses, covenant thresholds, FX paths and terminal values are assumptions unless directly evidenced.

Release remains candidate until remote workflow populates hashes, verifies the full model path and confirms workbook/release requirements.
