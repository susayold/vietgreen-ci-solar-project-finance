# PORTFOLIO_METHODOLOGY

Standalone project outputs are screened first. Hard-gate eligible projects are ranked by additive equity-NPV value density, subject to the fixed equity budget and parent-group concentration limit.

The portfolio view separately reports:

- selected project count and MWp;
- equity budget use;
- aggregate CFADS;
- pooled debt re-sized from aggregate CFADS, LLCR and leverage caps;
- pooled DSCR;
- parent, industry and regional concentration;
- scenario common-factor impacts.

Portfolio IRR is not used as the sole objective. A high aggregate IRR cannot rescue a failed legal, credit, site-continuity or PPA hard gate.
