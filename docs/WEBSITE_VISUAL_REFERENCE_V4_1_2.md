# Website visual provenance

The V5.1.3 presentation branch uses the prior recruiter website only as a visual
and information-architecture reference: navigation, eight routes, responsive
layout, evidence panels, charts, tables, frontier visualization and accessibility
patterns. It does not reuse predecessor facts, labels, workbook links or
portfolio claims.

The factual source is the frozen V5.1.3 model release
\`v5.1.3-recruiter-final\` at
\`ff69e15d211ff1abc88200574242ed2f1db49074\`. Website JSON is generated by
\`analytics/build_v5_1_3_website_data.py\` in GitHub Actions and published only
after validators, browser QA and exact-SHA Pages verification pass.
